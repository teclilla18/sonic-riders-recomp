01 / QUESTIONS

Frequently asked

What is Riders Plus?

A fan-made native port of Sonic Riders (GameCube, 2006). The game's PowerPC code is translated into C ahead of time (static recompilation) and the GameCube hardware is rebuilt natively, so it runs as a real app on each device. It is not an emulator.

Riders Plus is also the name of our optional gameplay rules (999 rings, Lv. 4 and 5, hold to boost, Auto spin); see Riders Plus rules.

Is it free? Do I need to buy anything?

The port is free. You need your own copy of Sonic Riders (USA) for GameCube, saved as a disc image. We don't sell, host or send the game.

Why can't I just download the game?

The finished game contains SEGA's code and assets, so it can never be shared. The installer builds it on your own computer from your own disc. That is also why you must never share what it builds.

Which disc image works?

Sonic Riders for GameCube, USA, revision 0 (game ID GXEE8P): a full .iso/.gcm, or Dolphin's .rvz/.wia. European, Japanese, modified, trimmed, GCZ, CISO and "Remove Junk Data" images don't work. Sonic Riders: Zero Gravity is a different game.

To make one from your disc you need a Wii that can read GameCube discs and CleanRip: illustrated dumping guide.

Do I need a GitHub account?

No. Downloading and reading never need one. Only posting a bug report or a discussion does (it's free).

Which devices does it run on?

Nintendo Switch (Switch, Lite, OLED, with custom firmware), Nintendo Switch 2 (experimental alpha, native homebrew), Windows 10/11, Android 11+ (64-bit), Linux / Steam Deck (test version) and iPhone / iPad (built on a Mac). See Download.

What does "experimental alpha" mean for Switch 2?

It is an early test build. It plays races at 2x resolution, but you may see stutter, short freezes, missing music or announcer audio, and slow startup. In Race Select the audio can break up badly and stay that way; this is not fixed yet. It updates by hand, separately from the stable version.

How fast does it run?

PC: 60 fps on the test PC (RTX 3060), 4 players included. Switch at normal clocks: a steady 30 fps in races; the 60 fps setting reaches 60 in lighter parts. Switch overclocked (CPU 1785 / GPU 1152 / memory 2133 MHz, at your own risk): 1–2 players mostly 60 fps. Android: 60 fps on a Galaxy S23 Ultra. iPhone / iPad: 60 fps on an iPhone 17 Pro and recent iPads.

How many players?

Up to 4 on one screen on Switch and PC, 2 on one phone. Online races between PC and Switch work on a home network today; internet play with room codes is the next big step on the Road to v1.0.

How do I update? Will I lose my saves?

On v0.8.3 or newer, open the installer or launcher and press UPDATE NOW. Saves, settings and your disc image stay. Step by step: update guide. On Android, never uninstall the app to update.

Can I use HD texture packs?

Yes, on every device. Packs made for Dolphin (folder GXEE8P) work as they are. Download the pack yourself (we don't host packs), then add it on the launcher's Mods page (PC) or under Texture packs in the Switch installer. On a Switch, pick the pack's smallest size: it loads faster. The easy texture pack guide has pictures for each device.

How do I open the settings menu?

Hold − on Switch, F1 or Back on PC, View on Steam Deck, or tap the top-left button on Android. The version number is in the About tab. All controls.

Is this official?

No. It is an unofficial fan project, not affiliated with, endorsed or sponsored by SEGA or Nintendo. See Legal.

02 / TROUBLESHOOTING

Something went wrong

Find the message or problem that matches yours.

Installer"does not match the known-good dump"Your image isn't the clean USA revision 0 dump (trimmed, compressed or modified). Dump it again, or convert it to a full ISO.
Installer"game ID is …"Only the USA release (GXEE8P) works.
InstallerThe installer can't find its setup filesYou ran it from inside the ZIP. Right-click the ZIP, choose Extract All…, and run it from the normal folder next to setup and tools.
InstallerCreateProcess failed, paths with ? or odd lettersYour folder path has letters outside English. Extract the ZIP to a short folder like C:\SonicRiders and run it there.
InstallerA download fails / INSTALL FAILEDCheck your internet connection or firewall and run the setup again; finished downloads are kept. Read the last line of setup.log next to the installer.
SwitchBlack screen or crash at startStart from a game with R held (not from the Album), and check the .iso is in /switch/sonicriders/.
SwitchSonic Riders isn't in the Homebrew MenuCheck that sonicriders.nro is directly in /switch/sonicriders/ (not in a second switch folder), then eject safely and reopen the menu.
SwitchSlow motion or low frame rateSet the frame rate to 30 or 60 fps (hold − for the settings), or overclock at your own risk.
SwitchAbout still shows the old versionMake sure the update went to the SD card you actually use, then launch again. Still old? See the booklet's fix.
PCThe game doesn't startCheck sonicriders.log in the install folder, and update your graphics driver (OpenGL 3.3 is needed).
Switch"An error has occurred" after sleepFixed in v0.9.0: update, then the console can sleep with the game open.
PCThe launcher shows FINISH UPDATEThe new version was unzipped over your install but never installed. Press FINISH UPDATE; saves and settings stay.
PCNo soundCheck Windows' default playback device; the game uses it.
LinuxThe installer opens in a text editorRight-click it → Properties → Permissions → tick Is executable, or run sh 'Install Sonic Riders (Linux).sh' in a terminal there.
Linux"SDL2 library … was not found"Install your distribution's SDL2 package (libsdl2-2.0-0 on Debian/Ubuntu, sdl2 on Arch/SteamOS, SDL2 on Fedora).
Android"0 Android devices are connected"Unlock the phone, use a data cable (not charge-only), choose File transfer, turn on USB debugging and tap Allow on the phone, then run the installer again.
Android"signatures do not match"The installed app was built on another PC. Uninstall it (this deletes its saves) and install again.
AndroidThe game closes on launch or while playingOpen it again and tap Share report (also saved in Download/SonicRiders/), and attach it to a bug report. Screen recording during races is not supported.

03 / REPORTING

Send a useful bug report

  1. Say your device, the version from the About tab, and exactly what you did.
  2. Attach the log: sonicriders.log (and sonicriders.prev.log) from the game folder, or setup.log for installer problems.
  3. Read it first and replace personal paths or names with [removed].
  4. Never attach your disc image, the built game, saves or console keys.

The form asks for everything step by step. A free GitHub account is needed to post.
