02 / BEFORE YOU START

What you need

Your own game

Your own copy of Sonic Riders (USA) for GameCube, saved as a disc image. Game ID GXEE8P, revision 0.

A full .iso or .gcm, or Dolphin's .rvz / .wia: the installer converts those for you. European, Japanese, trimmed or "Remove Junk Data" images don't work. The installer checks your file and tells you.

No disc image yet? You can make one from your disc with a Wii and CleanRip (illustrated guide).

A computer to build on

Windows 10 (1803+) or 11, 64-bit, about 4 GB free and internet the first time, for Switch 2, Switch, PC and Android. Linux and Steam Deck build on the device itself. iPhone / iPad builds on an Apple silicon Mac.

Nothing else to install: the setup downloads its own tools, each checked against a known fingerprint.

03 / NEVER USED GITHUB?

Downloading from GitHub

  1. GitHub is the free website that stores this project. Reading and downloading never need an account.
  2. The buttons above download the right file directly. If you open a release page instead, scroll to Assets and click the file whose name has your device in it, for example SonicRiders-PC-Setup-….zip.
  3. Do not pick Source code (zip) or Source code (tar.gz): those are for developers and contain no installer.
  4. Windows may say Windows protected your PC when you open the installer, because it is not signed by a company. Press More info, then Run anyway.

Never share what you build

The installer creates the game from your disc. Don't upload or share your built game (.nro, .exe, .apk, .ipa, .nsp) or your disc image. We never host or send game files, and nobody official will ever ask you for them.
