Find your next race

Arrange a time in an existing Riders community or with friends. Open the race lobby inside the game when everyone is ready.

Set up a private race

Open a group message in the app you already use with your friends. Share your platform, beta version and time zone to get everyone on the same build.

Send internet invite codes only in a private message to people you trust. In current test builds, a code can contain your public IP address.

What to put in a race request

“Anyone up for a couple of races? I’m on [platform], using [beta version]. I’m free [day / time / time zone] and can host.”

Play the Online Beta

Check the release notes for beta availability, supported devices and the right download for your platform.

  1. Install matching Online Beta versions on every device. Use your own Sonic Riders GameCube disc image to set up the game.
  2. Open Online from your build’s launcher or game menu. On the same home network, the host creates a LAN lobby and the other player joins it from the list.
  3. If your build offers internet play, the host opens an internet lobby, shares the code privately and accepts the other player’s join request.
