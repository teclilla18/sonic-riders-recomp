Riders Rebuilt Online Beta

Race your friends.

Get on the same beta build as a friend, open a lobby, and take your Extreme Gear online.

Online on: 💻 Windows PC · 🎮 Nintendo Switch (original, Lite, OLED) · 📱 Android (64-bit). Not yet on Switch 2, Linux / Steam Deck or iPhone / iPad.

Open Race Room How to play

Set up your next race

Use the Race Room to find a race partner, create a public or invite-only lobby, and chat with preset messages.

Plan the matchup

Compare platforms and beta versions before you play. If you’re setting up a race for later, include your time zone.

Set up a private race

The host creates the lobby in Riders Rebuilt. The other player joins from their own device.

Send internet invite codes only in a private message to people you trust. In current test builds, a code can contain your public IP address.

Sample invite

“Want to race? I’m on [platform] with [beta version]. I can host on [day] at [time and time zone].”

Play the Online Beta

Two players, one race, on Windows PC, Nintendo Switch (original, Lite and OLED) and Android phones. Any of them can race any other.

  1. Both players install the same Online Beta. Different versions refuse to connect, so update first. Use your own Sonic Riders GameCube disc image to set up the game.
  2. Open Online. In the game, open the settings menu (F1 on PC), go to Online and press Open Online. The game restarts into the online lobby; your offline save is kept.
  3. Same house? The host picks Host a race, and the other player picks it from the list. If it does not show up, use Join by address.
  4. Different homes? The host picks Host an internet race and sends the code privately. The friend joins with that code and sends their own code back; the host adds it and lets them in.
  5. The host’s rules count for both: Riders Rebuilt, Hold to boost, Ring Replenish and Limit Break Super Sonic. Auto spin is each player’s own choice.

Good to know: this beta is for 2 players. A 4-player update is coming soon. A room is either for the same house or for the internet, not both. The race runs at the speed of the slower device, so a lower resolution on a phone keeps it smooth.
