Installing Sonic Riders

First time? Pick your device and follow only that part. Tap a step to tick it off.

Colour key
  • Pink = a button to press
  • Teal = a file or program
  • Purple = SD card / hekate
  • Gold = what you'll see on screen

Your disc image every device

  1. You need your own copy of Sonic Riders (USA). Game ID GXEE8P. The download has no game files: the game is built from your disc.
  2. An .iso or Dolphin's .rvz both work. An ISO is not necessary. Pick your .rvz and the setup turns it into an .iso by itself (about a minute). Your .rvz stays as it is.
⚠️
Not supported: the European or Japanese versions, and RVZ files made with Dolphin's Remove Junk Data option. The setup checks your image and tells you if it's the wrong one.
🧰
You need: a Switch with custom firmware (Atmosphère) and the Homebrew Menu, about 2 GB free on the SD card, and a Windows 10 or 11 PC (it does the building).

Install 10–30 minutes, once

  1. Download SonicRiders-Switch-Setup-v0.8.4.zip from the latest release.
  2. Extract the whole zip to a folder, for example C:\SonicRiders. Don't run it from inside the zip. Use a path with only English letters and digits.
  3. Connect your SD card to the PC. How: see Connecting the SD card below.
  4. Open Install Sonic Riders (Switch).exe. Windows says Windows protected your PC? Press More info → Run anyway.
  5. Press Select disc... and pick your .iso or .rvz.
  6. Check your SD card is selected, and keep Copy the disc image too ticked.
  7. Press BUILD AND INSTALL and wait for Done. The first time it downloads its tools and builds the game. Later updates take seconds.
  8. Press Eject SD card, then put the card back in the Switch. Wait for Safe to remove the SD card now.

Connecting the SD card no need to take it out

  1. Restart the Switch into hekate. The way you normally start your custom firmware.
  2. Go to Tools → USB Tools → SD Card.
  3. Plug the Switch into the PC with a USB-C cable. The SD card shows up as a drive.
  4. After the install, press Eject SD card in the installer.
  5. In hekate press Close, then Home → Launch → your Atmosphère entry.
⚠️
Windows offers to scan and fix the drive? Choose Continue without scanning.
💳
Have a card reader? That works too. Just take the SD card out and put it in the PC.

Start the game

  1. Hold R while starting any installed game. Keep holding until the Homebrew Menu opens. Don't open it from the Album: the game needs the full memory.
  2. Choose Sonic Riders.
💡
60 fps? At normal clocks races run at a steady 30 fps. 60 needs an overclock (for example sys-clk), at your own risk.

🔍 Check it worked

In the game, hold − to open the settings menu.

Look at the version number in the About tab.

🧰
You need: a 64-bit Windows 10 or 11 PC, a graphics card with OpenGL 3.3 (any from the last ten years), about 4 GB free and internet the first time. A controller is recommended; a keyboard works too.

Install 10–30 minutes, once

  1. Download SonicRiders-PC-Setup-v0.8.4.zip from the latest release.
  2. Extract the whole zip to a folder you'll keep, for example C:\Games\SonicRiders. The game, your saves and settings live there. Use a path with only English letters and digits.
  3. Open SonicRidersLauncher.exe. Windows says Windows protected your PC? Press More info → Run anyway.
  4. Press Select disc... and pick your .iso or .rvz.
  5. Press INSTALL AND PLAY and wait. The first time it downloads its tools and builds the game. After that, PLAY starts it right away.
✅
All in one place. The launcher also has the settings, mods and button remapping (Controls page).

🔍 Check it worked

In the game, hold F1 to open the settings menu.

Look at the version number in the About tab.

🧰
You need: a 64-bit phone on Android 11 or newer, about 2 GB free on it, a USB cable, and a Windows 10 or 11 PC with about 4 GB free. The game is built on the PC and installed over USB.

On the phone once

  1. Open Settings → About phone → Software information. On other brands, Build number is right under About phone.
  2. Tap Build number 7 times. Until it says Developer mode is on.
  3. Open Settings → Developer options and turn on USB debugging.

Install 20–40 minutes, once

  1. Download SonicRiders-Android-Setup-v0.8.4.zip from the latest release.
  2. Extract the whole zip to a folder you'll keep, for example C:\SonicRiders.
  3. Connect the phone with the cable and unlock it. If it asks what the USB connection is for, choose File transfer.
  4. Open Install Sonic Riders (Android).exe. Windows says Windows protected your PC? Press More info → Run anyway.
  5. Press Select disc... and pick your .iso or .rvz.
  6. Tick I accept the Android SDK License, then press BUILD AND INSTALL.
  7. When the phone asks Allow USB debugging?, tap Allow. Tick "Always allow from this computer" to skip it next time.
  8. Wait for Done. It installs the app and copies your disc image to the phone by itself.
⚠️
Keep the same PC for updates. Android only accepts an update signed by the PC that made the app.

🔍 Check it worked

Start Sonic Riders from the phone's app list. You can unplug the cable.

The top-left button opens the settings menu; the version is in the About tab.

🧰
You need: a Linux PC or a Steam Deck (x86_64), about 4 GB free and internet the first time. It builds on the machine itself, no Windows needed.

Install 10–30 minutes, once

  1. Steam Deck: switch to Desktop Mode. Power → Switch to Desktop. Do steps 2–5 there.
  2. Download SonicRiders-Linux-Setup-v0.8.4.zip from the latest release.
  3. Extract it to a folder you'll keep, for example ~/Games/SonicRiders. Right-click the zip → Extract. Your disc image can stay where it is.
  4. Double-click Install Sonic Riders (Linux).sh. Choose Execute or Run if asked, then pick your .iso or .rvz.
  5. Wait for Done. Sonic Riders is now in the application menu (Games).
  6. Steam Deck Game Mode: in Steam, Add a Non-Steam Game to My Library → tick Sonic Riders → Add. Back in Game Mode it's under Non-Steam. Hold View for the settings menu.
💡
RVZ on Linux: converting a zstd RVZ (Dolphin's default) needs Python 3.14, or the zstandard package. If the setup says so, run python3 -m pip install --user zstandard or convert the RVZ to ISO in Dolphin once.
🧰
You need: an Apple silicon Mac (M1 or newer) with Xcode and Homebrew, about 6 GB free, a cable, and an iPhone or iPad on iOS 16 or newer. A free Apple ID is enough.

Install 15–30 minutes, once

  1. On your Mac, download SonicRiders-iOS-Setup-v0.8.4.zip from the latest release. Double-click it and keep the folder it makes, in a path with no spaces (for example ~/SonicRiders).
  2. Open START HERE (Mac).html in that folder. It shows, with pictures, how to allow the launcher the first time (it isn't signed by Apple).
  3. Open Sonic Riders Launcher. On Get ready, install what's missing. Each missing piece has its own button. Press Check again after each.
  4. On Build, press Select disc..., then BUILD THE APP. The app goes to Desktop/Sonic Riders iOS.
  5. On Install, follow the Sideloadly steps. Install the app, turn on Developer Mode, trust your Apple ID, and copy your disc image with Finder → your device → Files.
⚠️
Every 7 days: a free Apple ID app has to be renewed. The launcher's Renew page shows when and how, and can add a Calendar reminder.
