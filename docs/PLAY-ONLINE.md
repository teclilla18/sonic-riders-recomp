# Play online (Online Beta)

Race a friend online in **Riders Rebuilt**. This is a beta: 2 players, one race at a time.

## What you need

- **Two players for now.** A four-player update is coming soon.
- **Two devices**, any mix of: **Windows PC**, **Nintendo Switch** (original, Lite or OLED, modded) and
  **Android** phone (64-bit).
- **The same version on both.** If the versions are different, the game says so and does not connect.
  Update both first.
- Each player needs their own copy of the game, made from their own Sonic Riders (USA) disc image.

Not in this beta: Switch 2, iPhone / iPad, Linux, 3 or 4 players.

## Start a race

1. **Open Online.** In the game, open the settings menu (**F1** on PC), go to **Online** and press
   **Open Online**. The game restarts into the online lobby. Your offline save is kept.
   **On a Switch**, close the game and start **Sonic Riders Online** instead (its own icon in the Homebrew
   Menu, and on the HOME screen if you installed the HOME-screen icons). It opens straight into the lobby.
2. **Pick a name** the first time. Only this name is shown to the other player.
3. **Same house** (same Wi-Fi or network):
   - The host presses **Host a race**.
   - The other player picks the race from the list.
   - Not in the list? The other player presses **Join by address** and types the address the host's screen shows.
4. **Different homes** (over the internet):
   - The host presses **Host an internet race** and sends the code to the friend in a private message.
   - The friend presses **Join with a code** and types it.
   - The friend's screen shows their own code. They send it back, and the host presses **Add friend's code**.
   - The host presses **Let them in**, then **Start race**.
5. The host chooses the track. Both players choose a character and a board. Then race!

**Keep codes private.** An invite code contains the host's internet address. Only send it to people you trust.

## Rules in an online race

- **The host's settings count for both players:** Riders Rebuilt, Hold to boost, Ring Replenish,
  Super Sonic flight and **Limit Break Super Sonic**. The lobby shows them before the race.
- **Auto spin** is each player's own choice.
- **No CPU racers** online: only the two players race.
- **Super Sonic** is balanced: he boosts at 270 / 280 / 300 km/h, a boost costs **50 rings**, he gets rings back
  only from his ring magnet and from tricks, and he has no held boost. Turn on **Limit Break Super Sonic** for
  the overpowered Super Sonic from v0.9.0 (much faster, held boost up to 350 km/h). Everyone else can hold
  **B** to keep boosting.

## If something goes wrong

| Problem | Try this |
|---|---|
| "A different online version" | Install the same release on both devices. |
| The race is not in the list | Use **Join by address**, or check both are on the same network. Guest Wi-Fi often blocks it. |
| An internet join never arrives | Both players must add each other's code. If you are in the **same house**, don't use codes: use **Host a race** instead. |
| The race feels slow | The race runs at the speed of the slower device. Lower the resolution on a phone or a Switch. |
| Sound stutters | It follows the race speed: same fix as above. |

Still stuck? [Report a problem](https://github.com/teclilla18/sonic-riders-recomp/issues/new/choose) and attach
`sonicriders.log` from **both** devices (it is next to the game; on Android in `Android/data/net.srnative.sonicriders/files`, or `...sonicriders.standalone/files` for the no-PC app).
Leave invite codes out of public reports.
