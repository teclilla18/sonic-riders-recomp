Updating

Pick your device, then your version, and follow only that part. Your saves and settings stay. First time? Use the install guide.

Colour key:

Pink = a button to press

Teal = a file or program

Purple = SD card / hekate

Gold = what you'll see on screen

Coming from v0.8.2 or older one time only

  1. Download {{file:switch}} from the download page.
  2. Extract it over your old install folder. When asked, choose Replace.A new folder works too.
  3. Connect your SD card to the PC.How: see Connecting the SD card below.
  4. Open Install Sonic Riders (Switch).exe.
  5. Pick the same disc image → check your SD card is selected → press BUILD AND INSTALL.
  6. When it says Done, eject the SD card and play.This one time it builds the whole game (a few minutes, up to 30 on a slow PC). Later updates take seconds.

From v0.8.3 on one press

  1. Open Install Sonic Riders (Switch).exe.
  2. When a new version is out, it shows Update available in gold.
  3. Connect your SD card.How: see Connecting the SD card below.
  4. Press See what's new, then UPDATE NOW.It downloads, restarts, rebuilds and copies to your SD card by itself, usually in under a minute.
  5. Eject the SD card and play.

SD card not connected yet? No problem. The updater waits for it and carries on as soon as it shows up.

Connecting the SD card no need to take it out

  1. Restart the Switch into hekate.The way you normally start your custom firmware.
  2. Go to Tools → USB Tools → SD Card.
  3. Plug the Switch into the PC with a USB-C cable.The SD card shows up as a drive.
  4. When the update says Done, press Eject SD card in the installer. Wait for Safe to remove the SD card now. (On v0.8.3 and older: right-click the drive in Windows and choose Eject.)
  5. In hekate press Close, then Home → Launch → your Atmosphère entry.

Windows offers to scan and fix the drive? Choose Continue without scanning.

Nothing else to do. Your saves, settings, disc image and HOME-screen icon stay as they are.

In the game, hold − to open the settings menu.

Look at the version number in the About tab.

Switch 2 alpha updates are manual. They are separate from the original Switch's UPDATE NOW button. Never use an original Switch installer on this console. Quit the game normally before updating, and keep your SD card data.

Every alpha by hand

  1. Download {{file:switch2}} from the Switch 2 download. Always use the Switch 2 alpha release, not the stable "latest release".
  2. Extract it to a new PC folder and open Install Sonic Riders (Switch2).exe.
  3. Pick the same disc image and your SD card, read the shader compiler license, then press BUILD AND INSTALL. It replaces only the app and its build information. Saves, settings, caches and env.txt stay.
  4. Using FTP? Copy the new NRO and build-info.json to /switch/sonicriders-switch2/. Don't overwrite env.txt or settings.ini, and don't delete saves or caches.
  5. Eject the SD card safely, then start the game and check the version.

Coming from v0.8.2 or older one time only

  1. Open the Sonic Riders launcher.It shows Update available in gold.
  2. Press See what's new, then DOWNLOAD AND INSTALL.
  3. When it says Updated, press RESTART.
  4. On the Play page, press Rebuild now.This one time it builds the whole game (a few minutes). Later updates take seconds.
  5. When it's done, press PLAY.

Prefer the zip? Download {{file:pc}}, extract it over your old Sonic Riders folder (Replace), and run Install Sonic Riders (PC).bat with the same disc image.

Every version no one-press button on Linux yet

  1. Download {{file:linux}} from the download page.
  2. Extract it over your old install folder. When asked, choose Replace.On the Steam Deck, do this in Desktop Mode.
  3. Run Install Sonic Riders (Linux).sh with the same disc image.The first time on v0.8.3 or newer builds the whole game once. After that, only the parts that changed are rebuilt.
  4. When it says Done, play as usual.

Nothing else to do. Your saves stay in the same folder, and your Steam shortcut keeps working.

Every version no one-press button on iOS yet

  1. On your Mac, download {{file:ios}} from the download page.
  2. Unzip it into a folder whose path has no spaces.Your home folder works, for example ~/SonicRiders.
  3. Open Sonic Riders Launcher from the new folder.If macOS blocks it, follow START HERE (Mac).html in the same folder.
  4. On the Build page, pick the same disc image and press BUILD THE APP. When it says Done, the new SonicRiders.ipa is in Desktop/Sonic Riders iOS.
  5. On the Install page, install it over the old app.With Sideloadly: open SonicRiders.ipa, then Start. From the Mac: Install only (renewing).

Never delete the app to update. Deleting it removes your saves and the disc image copied to it.

Check it worked

Start the game, open the settings menu, and look at the version in the About tab.

Why is there still a short build? The finished game contains Sonic Riders' own code, so it can never be put in a download. The big conversion happens only on the first install; updates only rebuild the parts that changed.
